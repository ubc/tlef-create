# Observed problems and resolutions

These observations come from the 2026-09-28 expansion. Recheck upstream availability; these are not permanent exceptions.

| Symptom | Resolution / decision |
| --- | --- |
| Title-based package lookup fails | Virtual Tour is `H5P.ThreeImage`; Cornell Notes is `H5P.Cornell`; Complex Fill the Blanks is `H5P.AdvancedBlanks`; Find Multiple Hotspots is `H5P.ImageMultipleHotspotQuestion`. Verify official registry mappings. |
| Impressive Presentation Hub request returns 403 | The official h5p.org demo exposed `https://h5p.org/sites/default/files/h5p/exports/impressive-presentation-7141.h5p`, containing 1.0.3 and its editor widget. Use the public export link actually observed in the page, not a guessed URL. Upstream describes this type as experimental, with Chrome authoring limitations. |
| AdvancedBlanks Hub 403, old API 404, official demo export 404 | Built the original NDLANO repositories at pinned commits: runtime `9bd77ac4b2140a9b1b08d3393398a6fdf1e52ecc` (1.4.0), editor widget `270b587c88a2275e899cbeedcc616b7bde5a12e7` (1.0.0). Neither had a release tag. Record these as source snapshots. Hashes/build metadata live in the runtime manifest. |
| Source archive has descriptors but no dist bundles | Inspect upstream build scripts; use its pinned lockfile, `npm ci --ignore-scripts --no-audit --no-fund`, then the reviewed `npm run build`. Copy runtime descriptors, semantics, languages, licenses, upgrades, icons and compiled assets. Exclude node_modules, source package manifests, and build tooling. Inspect every declared file and CSS URL. |
| adm-zip extraction fails on valid Hub archives | Use Python `zipfile` through `maintain.py`; Hub packages can use ZIP64/data descriptors. Never ignore a failed extraction. |
| Package includes older versions of shared libraries | Retain newer installed patches and existing minor directories; check dependency closure after merge. A new minor can change the editor's selected version even without deleting old content. |
| Inventory reports pre-existing incomplete inactive versions | September 2026 retained Crossword 0.4, Dictation 1.4, and InteractiveBook 1.13 descriptors lack compiled bundles. Studio selects healthy Crossword 0.5, Dictation 1.3, and InteractiveBook 1.11 instead. Check target closures and newly introduced defects; do not call the entire retained library tree clean or delete older versions blindly. |
| Package requires newer core | Preserve its real core requirement. Upgrade core/editor as a separate validated scope or keep a compatible installed version. Never lower `coreApi` to silence validation. |
| Library appears installed but editor/player is blank | Check missing compiled JS/CSS, nested dependencies, custom editor widgets, and browser exceptions. A descriptor alone is not a functioning library. |
| Lots of 400 `action=libraries` responses in standalone acceptance server | Native editor POSTs `libraries[]`; the test server must use `express.urlencoded({ extended: true })`, matching CREATE. Do not patch production based on a malformed test harness. |
| Newly installed type becomes an AI choice | New target types use `editorOnly: true` and catalog mode `manual`; the AI endpoint and generation service must enforce this boundary. Form rendering proves neither AI semantics nor grading. |
| Native picker shows a gray H5P placeholder | Check whether the original `.h5p` actually contains a root `icon.svg`. The 2026-09-28 packages for `H5P.ImageMultipleHotspotQuestion`, `H5P.ImpressPresentation`, and `H5P.PersonalityQuiz` did not. CREATE supplies three original SVG icons as documented `createPatches`; keep their manifest and lock hashes current. Verify the rendered `<img>` has `naturalWidth > 0` in Chromium. |
| Automated fill appears valid but Studio Save says parameters are invalid | H5P text widgets commit values on native `change`. A browser automation `fill()` may show text without committing it; the title can remain blank in the Metadata popup. Use real keyboard typing and leave each field, or explicitly verify the metadata title and saved/reopened values. Do not infer a product defect from an uncommitted synthetic input. |
| Nested content form fails an immediate save | Wait for child library/editor initialization before validating or submitting. Speak the Words Set required a short additional wait; premature validation can fail or throw in a custom widget such as Information Wall. |
| Speech/AR/media type loads but cannot run a lesson without setup | Real microphone/camera/media/browser support and permissions remain necessary. Label browser/form acceptance accurately; do not promise those external capabilities were tested. |

If a browser fix changes a vendored asset, document the minimal CREATE patch and update its installed hash and lock digest. Keep upstream source provenance intact. For any new failure, record the reproducible symptom, root cause, narrow resolution, and verification evidence here only when it would change future maintenance decisions.
