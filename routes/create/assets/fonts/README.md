# PDF export fonts

Unmodified DejaVu Sans 2.37 regular, bold and oblique fonts, distributed under
LICENSE-DejaVu.txt. Upstream: https://dejavu-fonts.github.io/

Bundled locally so server exports do not depend on an operating-system font
installation or network access. The PDF embeds only the used glyphs. Coverage
includes common Latin/Greek/Cyrillic text, mathematical signs, arrows and numeric
superscripts/subscripts. This font does not promise full CJK coverage.
